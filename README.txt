SANSKAR LIBRARY — DEMO WEBSITE

How to preview:
1. Extract the ZIP file.
2. Open the folder and double-click index.html.
3. It opens in Chrome. The layout works on mobile and desktop.

Important:
- This is a static demo website. The enquiry form opens WhatsApp; it does not save enquiries to a database.
- Phone numbers and email are copied from the supplied poster.
- Confirm the exact shift timings with the client before publishing. The poster's Shift 2 appears to say 10:00 AM to 2:00 AM; this demo uses 10:00 AM to 2:00 PM so the five shifts fit a 24-hour day.
- Before going live, confirm the address, fees, facilities, final copy, domain and hosting with the client.
